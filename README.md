# monitoring

Introdução ao Prometheus e Grafana

Este projeto tem como objetivo apresentar os conceitos básicos de monitoramento de aplicações e infraestrutura utilizando Prometheus e Grafana, por meio de exemplos práticos e configurações iniciais.

O repositório reúne códigos de configuração, arquivos Docker Compose e exemplos de integração entre as ferramentas, demonstrando como realizar a coleta, o armazenamento e a visualização de métricas.

O conteúdo aborda configurações básicas do Prometheus para coleta de métricas, integração com aplicações e containers Docker, além da utilização do Grafana para criação de dashboards e acompanhamento de indicadores.

Também são apresentados exemplos de monitoramento do Traefik, permitindo visualizar informações como requisições HTTP, Entrypoints, Routers, Services e desempenho do proxy.

A proposta é servir como material introdutório e de aprendizado, auxiliando no entendimento das ferramentas e fornecendo uma base para a implementação de soluções de monitoramento em projetos futuros.
